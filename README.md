🗄️ Core Components & Architecture
index.html (Markup & Layout)
Section	Description

Projects	Filterable grid (Software, AI/ML, Systems) with modal popups

Scroll Progress	Dynamic reading progress bar across viewport bounds
⚙️ Setup & Local Development
1. Prerequisites
A modern web browser (Chrome, Firefox, Edge, Safari)
A lightweight local server tool (optional, e.g., VS Code Live Server)
2. Clone the Repository
bash
git clone https://github.com/PRANAV-MS25/My-Portfolio.git
cd My-Portfolio
3. Run Locally

Because this is a static web application built with vanilla web standards, you can open it directly:

Double-click index.html to open it in your default browser, or
Open the folder in VS Code and click Go Live using the Live Server extension.
