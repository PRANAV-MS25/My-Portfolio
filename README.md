## 🗄️ Core Components & Architecture

### `index.html` — Markup & Layout

| Section        | Description                                                             |
| :------------- | :---------------------------------------------------------------------- |
| **Header**     | Sticky navigation with responsive menu and quick links                  |
| **Hero**       | Introductory content, CTAs, interactive terminal widget, and statistics |
| **Marquee**    | Infinite scrolling technology ticker                                    |
| **About**      | Developer context, engineering mindset, and core principles             |
| **Projects**   | Filterable project grid with Software, AI/ML, and Systems categories    |
| **Stack**      | Languages, frameworks, tools, and technical foundations                 |
| **Experience** | Professional internship and educational timeline                        |
| **Contact**    | Direct contact options, email, and footer information                   |

### `script.js` — Interactivity & Logic

| Functionality          | Implementation                                                           |
| :--------------------- | :----------------------------------------------------------------------- |
| **Project Filtering**  | Category-based DOM filtering for All / Software / AI / Systems           |
| **Dynamic Modals**     | Project architecture and technical details displayed through modal cards |
| **Terminal Widget**    | Interactive command-line simulation with clipboard/email functionality   |
| **Walking Cat Sprite** | Event-driven character animation and interaction                         |
| **Scroll Progress**    | Dynamic reading-progress indicator based on viewport position            |

## ⚙️ Setup & Local Development

### 1. Prerequisites

* A modern web browser such as Chrome, Firefox, Edge, or Safari
* VS Code
* Live Server extension *(optional)*

### 2. Clone the Repository

```bash
git clone https://github.com/PRANAV-MS25/My-Portfolio.git
cd My-Portfolio
```

### 3. Run Locally

This is a static web application built using vanilla web technologies.

You can either:

* Open `index.html` directly in your browser, or
* Open the project in VS Code and select **Go Live** using the Live Server extension.
